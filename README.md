# From The Fog for Minecraft 26.3

From The Fog (Data + Resource Pack) v1.11.3, updated for **Minecraft Java 26.3** (data pack format 121.0, resource pack format 97.1).

**Changes from the 26.2 release**
- Updated `pack.mcmeta` formats for 26.3
- Converted advancements and predicates to the 26.3 predicate syntax
- Ported the item shader (Herobrine's glowing eyes) to the 26.3 shader pipeline
- Added a Korean (한국어) translation, with font fallback so Hangul displays in the menus
